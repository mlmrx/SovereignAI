# Code of conduct

This project is built on one rule — say what is true, including about
ourselves — and the same rule governs how we treat each other.

## The standard

- Be direct and be kind. Criticize code, copy, and claims freely; do not
  criticize people.
- Assume good faith in a report, a question, or a pull request — and give the
  reporter the benefit of the doubt when something is unclear.
- Respect people's time: read the ADRs before arguing with them, reproduce
  before reporting, and say when you are not sure.
- No harassment, discrimination, or personal attacks of any kind, in the
  repository, in Discussions, or anywhere the project is represented. No
  publishing of anyone's private information.

## Enforcement

Report conduct problems to `conduct@mysovereign.ai`. Reports are read by a
person, kept confidential, and answered. Consequences scale from a private
note to removal from the project's spaces, at the maintainers' judgment.

## Scope

All project spaces — the repository, issues, pull requests, Discussions —
and any place someone is representing the project.
