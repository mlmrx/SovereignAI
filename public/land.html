Three ways in. All of them yours.

No waitlist for self-hosting — download it, run it, own it. First launch opens a guided setup; drop in a ChatGPT or Claude export and your AI knows you within minutes.

Single binary No Node, no installer

One file for Windows, macOS, or Linux from GitHub Releases — runtime, app, and UI inside. Check it against the release's SHA256SUMS.txt, then run it.

One-line install Script it

irm https://raw.githubusercontent.com/mlmrx/SovereignAI/main/scripts/install.ps1 | iex on Windows, or the curl … | sh equivalent on macOS and Linux. Docker Compose if you prefer containers.

Any box you own VPS · homelab · on-prem

sovereign byoc deploy --host you@your-box puts a hardened instance on any Linux machine with SSH and Docker — health-checked upgrades, export-to-owner, verifiable delete.

Prefer reading before running? The whole engine is open source — zero runtime dependencies means the audit is actually finishable.
